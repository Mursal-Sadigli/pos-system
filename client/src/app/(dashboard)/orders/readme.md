## 🧾 Sifarişlər Tarixçəsi

- 🛒 Sifariş/Satış Modulu
  - Səbət idarəsi
    - Məhsulları əlavə et/çıxar
  - Endirim sistemi
    - Faiz, məbləğ, kupon kodları
  - Ödəniş üsulları
    - Nağd, Kart (Stripe), QR kod
  - Split ödəniş
    - Bir sifarişi bir neçə ödənişlə bölmək
  - Çap funksiyası
    - Qəbz çapı (thermal printer)
  - Sifariş statusu
    - Yeni
    - Hazırlanır
    - Tamamlandı
    - Ləğv olundu

- 📜 Sifariş tarixçəsi
  - Bütün satışların arxivi
